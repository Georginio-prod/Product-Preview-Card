## 📌 Présentation

Carte de **fiche produit** (parfum « Gabrielle Essence Eau De Parfum ») : image à gauche, catégorie, titre en police serif Fraunces, description, prix barré / prix promo et bouton « Add to Cart » avec icône.

Ce projet fait partie de ma **première série de défis Frontend Mentor (juin–juillet 2024)**,
réalisée en **HTML et CSS purs**, sans outil de build ni framework, pour consolider les
fondamentaux avant de passer à Sass, Tailwind puis Vue.

## ✨ Fonctionnalités

- Layout image + contenu côte à côte sur desktop, empilé sur mobile (`<picture>` pour changer d'image).
- Prix promotionnel + ancien prix barré (`<s>`).
- Bouton vert foncé avec icône panier et état de survol plus sombre.
- Polices Montserrat + Fraunces.

## 🛠️ Stack

| Élément | Détail |
|---|---|
| Structure | HTML5 sémantique |
| Styles | CSS3 (Flexbox / Grid, media queries), Google Fonts |
| Outils | Aucun build — fichiers statiques |
| Maquette | Frontend Mentor — mobile 375px / desktop 1440px |

## 📁 Fichiers

`index.html · style.css · public/ (images produit mobile / desktop, icône panier)`

## 🚀 Lancement

Aucune installation : cloner le dépôt et ouvrir le fichier HTML dans un navigateur.

```bash
git clone https://github.com/Georginio-prod/Product-Preview-Card.git
```

Pour un rechargement automatique, l'extension **Live Server** de VS Code fonctionne très bien.
